# 🛠️ Formatador de Texto e Planilhas (Chrome Extension)

Extensão para navegadores baseados no Chromium desenvolvida para otimizar o tratamento de dados no dia a dia em Google Planilhas, Excel Web, e-mails e formulários.

## 📋 Funcionalidades
- [x] Formatar CPF (`000.000.000-00`)
- [x] Mascarar CPF (LGPD) com modos flexíveis
- [x] Formatar CNPJ (`00.000.000/0000-00`)
- [x] Formatar Telefone e Celular
- [x] Extrair apenas números
- [x] Transformações de texto:
  - MAIÚSCULAS
  - minúsculas
  - Primeira letra da frase maiúscula
  - Primeira Letra De Cada Palavra
- [x] Remoção de acentos
- [x] Limpeza de espaços extras
- [ ] Interface gráfica rápida (Popup) *(Em desenvolvimento)*
- [ ] Ações rápidas com o botão direito (Menu de contexto) *(Em desenvolvimento)*

## 🚀 Tecnologias
- JavaScript (ES6+ Modules)
- Chrome Extension API (Manifest V3)
